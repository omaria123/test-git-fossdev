# Библиотека simplemath-new

**simplemath-new** — это простая Python-библиотека, предоставляющая базовые математические функции: сложение и умножение. Проект демонстрирует процесс создания, упаковки и публикации Python-пакета в тестовом репозитории TestPyPI.

Цель проекта — показать полный цикл разработки библиотеки: от написания кода и тестов до автоматизации сборки через Makefile и публикации пакета.

---

## Логика работы

### Код библиотеки

Библиотека находится в папке `src/simplemath/` и предоставляет две функции с аннотациями типов:

- **add(a: int, b: int) -> int** — возвращает сумму двух целых чисел.
- **multiply(x: float, y: float) -> float** — возвращает произведение двух чисел.

Файл `__init__.py` делает функции доступными для импорта: `from simplemath import add, multiply`.

### Тестирование

Тесты написаны с использованием `pytest` и находятся в папке `tests/`. Они проверяют:

- Сложение положительных, отрицательных чисел и нуля.
- Умножение целых и дробных чисел.

Тесты гарантируют, что библиотека работает корректно при любых входных данных.

### Автоматизация (Makefile)

Makefile предоставляет единую точку входа для всех операций. Каждая команда использует интерпретатор из виртуального окружения `.venv/`, что исключает ручную активацию и делает процесс воспроизводимым.

Доступные команды:

- `make setup` — создаёт виртуальное окружение, устанавливает `pytest` и устанавливает библиотеку в режиме разработки (`pip install -e .`).
- `make test` — запускает все тесты с помощью `pytest`.
- `make build` — собирает пакет: создаёт исходный дистрибутив (sdist) и wheel.
- `make publish-test` — публикует собранный пакет на TestPyPI с помощью `twine`.
- `make clean` — удаляет виртуальное окружение, временные файлы и артефакты сборки.

### Упаковка и публикация

Конфигурация пакета описана в файле `pyproject.toml`. В нём указаны:

- имя пакета — `simplemath-new`
- версия — `0.1.1`
- описание, лицензия, автор
- минимальная версия Python — 3.9
- ссылки на GitHub репозиторий

Публикация выполняется на TestPyPI — тестовый индекс пакетов, который не влияет на основной PyPI. Это позволяет безопасно пробовать процесс распространения библиотеки.
